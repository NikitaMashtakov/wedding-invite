# Приглашение на свадьбу

Статический сайт-приглашение. Внешних запросов нет: шрифты, стили, скрипты и
фотографии лежат в репозитории. Пути относительные, поэтому сайт одинаково
работает и в корне домена, и в подкаталоге (GitHub Pages).

Исходно — сохранённый вручную шаблон с wedwed.ru, вычищенный до того, что
реально используется.

## Стек

Никакой сборки и фреймворков:

| | |
|---|---|
| Разметка | один `index.html` |
| Скрипты | jQuery 3.6 и `main.js` шаблона (таймер, календарь, модальное окно) |
| Стили | CSS шаблона, свои шрифты через `@font-face` |

`npm install` не нужен — достаточно раздать каталог статикой.

## Запуск

```bash
./serve.sh          # http://localhost:8000/
./serve.sh 9000     # другой порт
```

Открывать по `http://`, а не двойным кликом по файлу: через `file://` браузер
заблокирует часть загрузок.

## Публикация

**GitHub Pages.** Settings → Pages → ветка `main`, каталог `/ (root)`.
`.nojekyll` в корне уже есть — он не даёт Jekyll трогать статику.

**Netlify / Vercel / Cloudflare Pages.** Build command пустой, publish
directory — корень репозитория.

## Анкета → Google-таблица

Гость заполняет форму (имя, придёт или нет, какие напитки — мультивыбор),
ответ падает строкой в вашу Google-таблицу.

**Настройка, один раз:**

1. Создайте таблицу в Google Таблицах.
2. Расширения → Apps Script. Удалите содержимое редактора, вставьте
   `google-apps-script.gs` из этого репозитория целиком. Сохраните.
3. Развернуть → Новое развёртывание → «Веб-приложение»:
   запуск **от моего имени**, доступ — **у всех**. Развернуть, разрешить доступ.
4. Скопируйте URL веб-приложения (оканчивается на `/exec`) и вставьте его в
   `index.html` в переменную `RSVP_ENDPOINT` (внизу файла).

Проверить развёртывание можно, открыв тот же `/exec` в браузере: он ответит
`{"ok":true,"rows":N}`.

Пока `RSVP_ENDPOINT` пустой, форма работает, но ответы только пишутся в консоль
браузера — гость при этом всё равно видит «Спасибо».

Колонки в таблице: время, имя и фамилия, придёт, спутник(ца), напитки.
Список напитков задан прямо в разметке `index.html` (`name="alco[]"`); подпись
для таблицы берётся из `<label>`, так что достаточно править разметку в одном
месте. Форм на странице две — на широком экране показывается встроенная, на
телефоне открывается модальное окно; списки в них нужно держать одинаковыми.

Поле «спутник(ца)» в разметке есть, но скрыто классом `sm-hidden` — уберите
класс в обеих формах, если хотите его показать.

## Что внутри

```
index.html                              страница приглашения
google-apps-script.gs                   бэкенд анкеты для Google-таблицы
wedding.ics                             событие для кнопки «Добавить в календарь»
serve.sh                                локальный запуск
.nojekyll                               отключает Jekyll на GitHub Pages
sitemaker/css/                          style10 + шрифтовые css
sitemaker/fonts/                        Cormorant Garamond (заголовки), Gilroy (текст)
sitemaker/js/jquery-3.6.0.js
sitemaker/templates/template26/          css/js/картинки шаблона
sitemaker/userdata/58491/<project>/     фотографии
```

## Что поправить под себя

| Что | Где |
|---|---|
| Имена, дата | `<script>` в `<head>` (`d_groom`, `d_bride`, `d_mdate`) и текст в разметке |
| Тексты блоков | атрибуты `data-sm-text` в `index.html` — текст лежит рядом, в самом теге |
| Фотографии | `sitemaker/userdata/58491/<project>/images/` |
| Телефоны, ссылки | `href="tel:..."`, ссылка 2ГИС — по тексту `index.html` |
| Кнопка 2ГИС | ссылка в `<a id="btn-2gis">` |
| Кнопка календаря | файл `wedding.ics` и ссылка на Google Календарь рядом с ней |
| Адрес для анкеты | `RSVP_ENDPOINT` внизу `index.html` |
| Шрифт заголовков | `sitemaker/css/fontcss/cormorant_garamond.min.css`, псевдоним `SMHeadersFont` |
| Шрифт текста | `sitemaker/css/fontcss/gilroy.min.css`, псевдоним `SMTextsFont` |

> **При смене даты** правьте четыре места: `d_mdate` в `<head>`, день на первом
> экране (`data-sm-day`, `data-sm-tmonth-rod`, `data-sm-fyear`), подписи года и
> месяца в блоке календаря и `DTSTART`/`DTEND` в `wedding.ics` вместе с
> параметром `dates=` в ссылке на Google Календарь. Сетка календаря и обратный
> отсчёт считаются из `d_mdate` сами. Дату нужно держать в будущем: `main.js`
> игнорирует прошедший год и откатывается на запасное значение шаблона.

## Отличия от исходного шаблона

* **Заставка убрана.** Экран с перетаскиваемой кнопкой «Открыть приглашение»
  удалён, вместе с ним — jQuery UI и touch-punch, которые нужны были только ему.
* **Анимации появления убраны.** Раньше секции ждали скролла (`opacity:0`),
  а текст всплывал с задержками 2–3 с. Теперь всё видно сразу. Осталась одна
  анимация: первая фотография мягко проявляется при загрузке; она подчиняется
  `prefers-reduced-motion` и не зависит от скриптов.
* **Слайдер пожеланий заменён списком**, поэтому удалены slick и fancybox.
* **Анкета** уходит в Google-таблицу вместо сервера wedwed.ru.
* **Шрифты.** Заголовки — Cormorant Garamond 400 (Google Fonts, OFL 1.1),
  текст — Gilroy. Оба подключены через псевдонимы `SMHeadersFont` и
  `SMTextsFont`, на которые завязаны классы шаблона, так что шрифт меняется
  подменой одного файла. Cormorant оставлен в подмножествах cyrillic и latin,
  у Gilroy оставлены шесть начертаний, которые реально встречаются на странице.
  Если добавите текст с диакритикой или другим начертанием — верните
  соответствующий файл.
* **Вычищено всё лишнее.** В репозитории остались только файлы, которые
  страница действительно запрашивает: проверено записью всех сетевых запросов
  на 390 / 768 / 1440 px, со скроллом по всей странице, открытием модального
  окна и перебором всех полей формы.

## Права

Шаблон, часть шрифтов и изображений принадлежат wedwed.ru и авторам
использованных библиотек. Это личная копия конкретного приглашения.
